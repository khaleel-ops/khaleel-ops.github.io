# Mohammed Barkatullah — resume

Interactive resume site. A single static `index.html` with no build step.

- `index.html` — the page
- `avatar.jpg` — profile picture
- `logos/` — company and university logos
- `projects/` — preview image for the Experiments section

Run locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
